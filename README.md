# DJGARDO APP (djgardo)

## Requisitos

- Node.js 22.18+, 24.11+ o 26+
- npm 10+

## Instalar dependencias

```bash
npm install
```

## Ejecutar localmente

```bash
npm run dev
```

La aplicación estará disponible en <http://127.0.0.1:9000>.

## Formato y lint

```bash
npm run lint:check
```

## Compilar para producción

```bash
npm run build
```

La configuración de Quasar está en [quasar.config.js](./quasar.config.js).
